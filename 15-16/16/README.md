# Практика 16 - WebSocket + Push

## Запуск

```bash
cd 15-16/16
npm install
npm start
```

Открыть `http://localhost:3001`.

## Проверка

- Открыть приложение в двух вкладках.
- Добавить заметку в одной вкладке и увидеть toast-уведомление в обеих.
- Нажать "Включить Push", разрешить уведомления и добавить новую заметку.
- Проверить `POST /subscribe`, `POST /unsubscribe` и событие `push` в DevTools.

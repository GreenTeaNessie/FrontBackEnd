# Практическое занятие №3

В этой папке собраны воспроизводимые артефакты проверки для двух частей задания:

1. Проверка локального API из практического занятия №2.
2. Выполнение 5 запросов к внешнему API курсов валют.

## Что находится в папке

- `requests.http` — 3 запроса к локальному API из `../1-2/2` и 5 запросов к внешнему API через локальный прокси.
- `server.js` — вспомогательный прокси для ExchangeRate API.
- `.env.example` — шаблон переменной окружения для ключа.
- `verification-report.md` — единый файл-шаблон, в который можно вставить скриншоты результатов.

## Шаги проверки

### 1. Локальный API из задания №2

1. Перейдите в папку `../1-2/2`.
2. Запустите сервер командой `npm start`.
3. Выполните первые 3 запроса из `requests.http`.
4. Сохраните результаты в виде скриншотов и вставьте их в `verification-report.md`.

### 2. Внешний API

1. Скопируйте `.env.example` в `.env`.
2. Укажите реальный `EXCHANGE_RATE_API_KEY`.
3. В этой папке выполните `npm start`.
4. Выполните 5 внешних запросов из `requests.http`.
5. Сохраните результаты в виде скриншотов и вставьте их в `verification-report.md`.

## Примечание

Финальная склейка скриншотов в один файл остаётся ручным шагом перед сдачей работы.

# Практика 17 - Reminder Push

## Запуск

```bash
cd 17
npm install
npm start
```

Открыть `http://localhost:3001`.

## Проверка

- Включить Push и разрешить уведомления.
- Создать обычную заметку и проверить WebSocket-toast.
- Создать напоминание на ближайшее время.
- Дождаться системного Push-уведомления.
- Нажать "Отложить на 5 минут" и проверить повторное уведомление.
